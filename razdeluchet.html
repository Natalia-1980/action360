НДС

раздельный учет — обязателен
  • условие: есть облагаемые и необлагаемые операции. Входной НДС по общехозрасходам распределяется пропорционально выручке.
  • правило 5%: если доля расходов на необлагаемые операции ≤5% от всех расходов, учет можно не вести, но налоговики часто оспаривают. Считать долю необлагаемых операций все равно нужно.
  • последствия ошибки: отказ в вычете НДС, доначисление, штраф (ст.122 НК).
Основная ставка НДС — 22%. Не действует часть льгот, например на банковские услуги, по эквайрингу.
ставки 22, 10, 0%

Налог на прибыль

раздельный учет — при разных базах / ставках
  • обязательные случаи: резиденты ОЭЗ, СПВ, организации с госфункциями, операции с ценными бумагами, дивиденды. Отдельное разделение убытков по видам деятельности.
  • нулевой доход: раздельный учет нужен даже при подготовительных расходах (если доходов нет, но расходы есть).
  • учетная политика: порядок закрепляется до налогового периода. Нарушение = потеря льготы с начала года + штраф 20% (ст.122).
Общая ставка → 25% ОЭЗ / СПВ: до 13,5% (регион) ИТ-ставка 5% (до 2030)

Страховые взносы

раздельный учет не требуется
  • льготные тарифы (15% / 7,6%) применяются ко всем работникам, если выполнены условия: МСП в приоритетных отраслях с долей профильного дохода ≥70% или ИТ-аккредитация.
  • контроль доли обязателен: падение ниже порога → потеря права с начала расчетного периода (пересчет 30% на все выплаты + штраф).
  • актуально: код тарифа 32 — льготы только для МСП из приоритетных отраслей по распоряжению №4125-р.
приоритетные МСП: 15% сверх 1,5 МРОТ обрабатывающие: 7,6% сверх 1,5 МРОТ ИТ: 15% предельная / 7,6% сверх

Налог на имущество

объектный раздельный учет
  • когда нужен: разные ставки для разных категорий (основная 2,2% / льгота 0%), кадастровые объекты vs среднегодовая стоимость, филиалы в разных регионах.
  • уведомительный порядок: без заявления в ИФНС льгота не применяется, даже при формальном праве.
  • особенность: многие региональные льготы отменены. Требуется ежегодная проверка регионального закона.
ставка до 2,2% (ср/год) кадастр: до 2%

Транспортный налог

поштучный учет ТС
  • раздельный учет обязателен: при разных ставках (лошадиные силы, тип) и при региональных льготах на часть автопарка (электромобили, резиденты СПВ).
  • льготы заявляются: через заявление в ИФНС. При льготе только для части ТС — четкая сегментация по ПТС.
  • актуально: актуализированы коды льгот, повышающие коэффициенты на дорогие авто (перечень Минпромторга).
ставки по регионам электромобили: льготы уточнять

ОЭЗ / СПВ: убытки и нулевой доход

строгое разделение баз
  • резиденты ОЭЗ и СПВ: обязаны разделять доходы, расходы и убытки по льготируемой и нельготируемой деятельности. Нельзя уменьшать льготную базу на убытки от аренды/иных операций.
  • нулевой период: раздельный учет ведется даже при отсутствии выручки (подготовительные расходы). Иначе ИФНС отказывает в признании расходов будущих лет.
  • учетная политика: порядок определения базы обязательно фиксируется до налогового периода, в котором получена первая прибыль по соглашению.
пример: убыток от аренды 5 млн руб., прибыль от льготы 10 млн. Смешивать базы нельзя → доначисление налога, штраф.
пониженные ставки ОЭЗ: до 13,5% СПВ: спецрежим

Когда учет не нужен

ситуации без раздельного учета
  • По налогу на прибыль: все доходы/расходы облагаются по единой ставке, без льгот по видам деятельности.
  • Страховые взносы: раздельный учет не требуется, но обязательный контроль доли профильного дохода (≥70%).
  • Для НДС — только если все операции облагаемые либо. При правиле 5% рассчитывайте долю необлагаемых расходов.
цена нарушения раздельного учета:
  • Потеря льготы с начала налогового периода (пересчет по максимальной ставке).
  • Штраф 20% / 40% по ст.122 НК + пени за каждый день.
ежеквартальный аудит: доля профильного дохода, статус аккредитации, разделение убытков (ОЭЗ/СПВ), актуальность учетной политики.
